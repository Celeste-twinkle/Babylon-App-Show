# LUT 滤镜预设

本目录当前保留 30 个偏场景、物品、空间氛围的 `.cube` LUT，已排除人像、美妆、婚礼、肤色优化类滤镜。

来源策略：

- `luttie-*.cube`：从 Luttie 免费公开 LUT 页面下载的 `.cube` 文件。
- `fresh-*.cube`：参考 FreshLUTs Most Popular LUTs 热门下载榜中偏场景/物品的 LUT 名称和下载量，生成同风格 `.cube`，用于本项目内置滤镜体验。

参考页面：

- https://luttie.app/luts
- https://freshluts.com/most_popular_luts

FreshLUTs 未登录状态下详情页下载按钮跳转注册页，因此没有直接抓取其登录态下载文件；本目录只保留公开可直链下载文件和项目内生成的场景风格 LUT。
